


# QueueMaster Pro - Professional Queuing System

A modern, self-contained queuing system with customizable tellers, receptionist panels, real-time monitor display, and voice announcements using browser's built-in speech synthesis.

## Features

- **No API Keys Required** - Works completely offline after initial setup
- **Voice Announcements** - Uses browser's Web Speech API (no external dependencies)
- **Multi-role Support** - Admin, Receptionist, Teller roles
- **Real-time Monitor** - Public display with grid/list layouts
- **Ticket Management** - QR code generation, printing, and tracking
- **Local Storage** - All data persists in browser storage
- **Responsive Design** - Works on desktop and tablets

## Run Locally

**Prerequisites:** Node.js 18+ and npm/yarn

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd queuemaster-pro

2. Install dependencies
   ```bash
   npm install

3. Run the development server
   ```bash
   npm run dev

4. Open your browser and navigate to
   http://localhost:3000
